Hero banner

The big banner at the top of Home. Jelly Cinema draws it itself; if the Media Bar plugin is installed, Media Bar draws it instead and the "Jelly Cinema banner" settings below don't apply.

Every viewer only sees titles from libraries they can open and within their rating limits.

Theater Mode

When nobody touches Home for a while, the banner and its trailer fill the screen. The first key press only wakes it.

Top 10

Numbered rows of the most-watched movies and shows. Each person only sees titles they're allowed to open.

Picks

A weekly row of well-rated family movies the viewer hasn't watched.

Seasonal themes

Holiday overlays (snow, leaves, hearts and more) and themed movie rows by date.

Leave out "calendar" to use the built-in 13-theme calendar. Dates: "MM-DD", "easter" or "thanksgiving", with optional offsets like "easter-7".

Permission check

Builds the Top 10, Picks and seasonal rows for every user and confirms each title is one that user is allowed to open.

This puts every Jelly Cinema setting back to how it came out of the box, including the server name, colors, sign-in message and seasonal rows. Your libraries, users and movies are not touched.
