# Security

Jelly Cinema shows titles on the Jellyfin home screen, so the most important promise it makes is that nobody
sees a title from a library they can't open or above their rating limit.

If you find a way around that, or any other security problem, please don't open a public issue. Instead, use
**Report a vulnerability** on the repository's Security tab, or email **apps@techsystems23.com**. Include your
Jellyfin version, the Jelly Cinema version and the steps to reproduce it. You'll get a reply within a few days,
and a fix will go out as quickly as possible.

Only the latest release gets security fixes.
